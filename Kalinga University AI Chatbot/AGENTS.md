# Kalinga University AI Chatbot — Agent Instructions

## Core Rules
1. Use the provided source material as the primary factual source.
2. Prefer official Kalinga University sources for verification.
3. Never invent university-specific information.
4. Clearly distinguish current and historical information.
5. Never present individual placement examples as guarantees.
6. Never present historical placement statistics as current.
7. Store source URLs with factual knowledge-base records.
8. Keep the NLP pipeline explainable.
9. Run tests after significant changes.
10. Verify the application before declaring completion.
11. Keep frontend and backend independently runnable.
12. Do not expose secrets.
13. Keep code readable and suitable for a college minor project.
14. Document important architectural decisions.
