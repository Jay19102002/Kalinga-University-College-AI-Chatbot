# Project Documentation Skill

## Documents Created
- `README.md`: System overview, setup, running instructions, and architecture summary.
- `docs/project-report.md`: Formal minor project report (Abstract, Introduction, Architecture, NLP Methodology, Results, Conclusion).
- `docs/architecture.md`: Mermaid sequence and flowcharts.
- `docs/dataset.md`: Dataset provenance and format documentation.
- `docs/testing.md`: Test plan and Pytest execution logs.
