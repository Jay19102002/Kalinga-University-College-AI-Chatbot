# Kalinga Knowledge Base Skill

## Purpose
Maintain factual knowledge JSON files under `data/knowledge_base/` with exact source provenance.

## Rules
- Store source title and URL for every entity record.
- Distinguish published individual high package highlights from average CTC stats.
- Never invent missing program fees; return explicit fallback directing to official fee pages.
